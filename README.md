# WorkHard SFX — Release Channel

This repository hosts release metadata and downloadable packages for the WorkHard SFX Premiere Pro extension's in-app updater. It does not contain the extension's source code.

- `version.json` — machine-readable pointer to the latest version, used by the extension's built-in update checker.
- Release assets (zip files) are attached to GitHub Releases, not committed to this repo.
